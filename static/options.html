Settings save as you change them. Reload x.com if it's already open.

AI brain

This makes it smart: it understands anything you say, answers questions, remembers the conversation, writes replies, and can do anything on X. All options below are free. Add more than one key and it switches automatically when one is busy or down.

You can also switch by voice: say “AI on” or “AI off”.

Groq (recommended)

Free, no card: go to console.groq.com/keys, sign up, click Create API Key, paste it here. It also powers the sharper hearing below.

Short commands stay instant. Longer sentences, DMs and replies are re-checked by Whisper, which adds about half a second.

Google Gemini (backup, web search)

Free, no card: aistudio.google.com/apikey → Create API key. If project creation fails, create a project at console.cloud.google.com first, then import it. Free-tier requests may be used by Google to improve its models.

Ollama (offline backup)

Install from ollama.com, then run ollama pull llama3.2. Private and unlimited, but no web search and needs a decent computer.

Claude (optional, paid)

Key from console.anthropic.com. Leave empty to stay free.

Your writing style

Used when it writes replies, posts and DMs for you, so they sound like you.

Listening

A wake word stops it reacting to conversations around you. “Stop”, “send” and “cancel” always work without it.

Built-in commands are in English; other languages work through the AI.
